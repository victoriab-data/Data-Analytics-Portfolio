# 🎗️ Breast Cancer Patient Outcomes Dashboard

An end-to-end healthcare analytics project using SQL (MySQL) and Power BI to clean, validate, analyze, and visualize breast cancer patient outcomes.

## Tools

- SQL (MySQL)
- Power BI

## Dataset

- Raw records: 1,338
- Final analytical records: 334
- Final fields: 9
- Analysis period: 2017–2019

## Key KPIs

- Total Patients: 334
- Alive Patients: 255
- Dead Patients: 66
- Average Age: 59
- Insurance Paid: ₦4.7M
- Survival Rate: 79.4% (among patients with known outcomes)

## Key Insights

- Stage II was the largest tumour-stage category with 189 patients.
- The 50–59 age group had the highest patient concentration.
- Other was the most frequent surgery category with 105 procedures.
- Modified Radical Mastectomy followed with 96 procedures.
- Approximately ₦4.7 million in insurance payments were recorded.

## Project Workflow

Raw Data → SQL Cleaning & Validation → Clean Dataset → Power BI Dashboard → Insights & Recommendations
