## 🎗️ 2. Breast Cancer Patient Outcomes Dashboard

### Project Overview

An end-to-end healthcare analytics project focused on transforming breast cancer patient records into a clean, analysis-ready dataset and an interactive Power BI dashboard.

SQL/MySQL was used for data exploration, cleaning, validation, and preparation before the final analysis was completed in Power BI.

### Tools
- SQL (MySQL)
- Power BI

### Data Preparation

- Raw dataset: 1,338 records and 16 fields
- Final analytical dataset: 334 patient records and 9 fields
- Validated patient IDs
- Checked duplicate records
- Checked missing values
- Standardized categorical and date fields
- Prepared insurance payment data for analysis

### Dashboard KPIs

- Total Patients: 334
- Alive Patients: 255
- Dead Patients: 66
- Average Age: 59
- Insurance Paid: ₦4.7M
- Survival Rate: 79.4%

### Key Insights

- 334 patients were included in the final analysis.
- The survival rate among patients with specified Alive/Dead outcomes was 79.4%.
- Stage II was the largest tumour-stage category with 189 patients.
- The 50–59 age group had the highest patient concentration.
- Other was the most frequent surgery category with 105 procedures.
- Modified Radical Mastectomy followed with 96 procedures.
- Approximately ₦4.7 million in insurance payments were recorded.
