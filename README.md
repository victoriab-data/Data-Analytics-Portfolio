 🚨 Fraud Detection & Risk Analysis Dashboard

📌 Project Overview

This project analyzes banking transaction data to identify fraudulent activities, evaluate transaction risks, and provide business recommendations using SQL and Tableau.

The project demonstrates the complete data analytics workflow—from data cleaning to dashboard development and business insight generation.

---

 🎯 Business Problem

Financial institutions process thousands of transactions daily. Identifying suspicious activities quickly is essential to reduce financial losses, improve security, and strengthen customer trust.

---

 🎯 Project Objectives

- Clean raw banking transaction data using SQL.
- Standardize inconsistent records.
- Identify fraud patterns and high-risk transactions.
- Build an interactive Tableau dashboard.
- Generate actionable business recommendations.

---
 🛠️ Tools Used

- SQL (MySQL)
- Tableau
- Microsoft Excel

---

 📊 Dashboard Highlights

The dashboard includes:

- Total Transactions
- Total Transaction Value
- Fraud Rate
- Average Risk Score
- Fraud by Transaction Type
- Fraud by Channel
- Fraud Trend Over Time
- Fraud Distribution

---

 💡 Key Insights

- Certain transaction channels recorded higher fraud rates.
- Some transaction types consistently showed elevated risk scores.
- Fraud trends varied over time, highlighting periods of increased risk.
- The analysis supports faster fraud monitoring and informed decision-making.
